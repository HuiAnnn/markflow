# 写下想法，让思路自然生长。

欢迎来到 **Markflow**。一个安静、专注的 Markdown 写作空间。

在这里，文字就是界面。点击这一段开始编辑，Markdown 标记会在你需要时出现，离开时轻轻隐去。

## 从一篇笔记开始

打开本地文档，或用 **⌘ N** 写下新的想法。使用 **⌘ S** 保存到自己的文件夹，所有内容都由你掌握。

> 好的写作工具，让你忘记工具的存在。

## 写作，也可以很轻盈

| 你想做的事 | 快捷方式 |
| :--- | :--- |
| 打开一篇 Markdown | ⌘ O |
| 保存当前文档 | ⌘ S |
| 切换源码与即时渲染 | ⌘ E |
| 搜索整个文件夹 | ⌘ ⇧ F |

### 给复杂的想法一点结构

用列表理清思路，用表格组织信息，也可以写下公式 $E = mc^2$。

```mermaid
graph LR
  A[一个想法] --> B[写下来]
  B --> C[慢慢打磨]
  C --> D[分享出去]
```
