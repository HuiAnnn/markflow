# 1.1.1 焦点样式回归检查

## 问题与原因

点击搜索框后，底部出现过厚蓝边，顶部角落也残留蓝色。外侧焦点轮廓超过了搜索面板的滚动边界，被裁切后形成不完整的线条。键盘聚焦大纲第一项时，也复现了相同的裁切问题。

## 修复

- 搜索框改用边框和内描边表达焦点，完整贴合圆角，失焦后恢复普通边框。
- 大纲、文件项、目录标题和搜索结果的键盘焦点轮廓改为向内绘制，避免滚动视口裁切。
- 保留键盘焦点提示和正常选中状态；工具栏按钮鼠标点击时不会额外留下键盘焦点圈。

## 检查范围

新增 4 项 Electron 回归测试：

1. 浅色、深色、暖纸主题下，搜索焦点不越出滚动边界；失焦恢复；鼠标和 Tab 均能聚焦并输入。
2. 大纲首行的键盘焦点完整显示在列表视口内。
3. 工具栏鼠标点击不残留键盘轮廓；设置中的下拉控件、开关仍有键盘焦点提示。
4. 125% 缩放下，文件项和搜索结果的键盘焦点不被侧栏裁切。

原有文件打开、保存、自动保存、撤销、导出和主题测试也继续保留。完整验证结果为 8 项单元测试、21 项已打包应用端到端测试通过。

修复前，搜索框和大纲两条回归测试均按预期失败；修复后通过。截图使用通用示例文稿，未包含私人文件。
